# "Digital Business Card" Project

This is a simple digital business card I built from scratch using HTML and CSS. It puts my photo, short bio, interests, email button, and social media links all in one neat card on the screen.

## Built With

### Tech Stack

* HTML
* CSS
* Visual Code Editor

### Key Features

* HTML & CSS Basics: Structuring a clean webpage with semantic tags and styling layouts, colors, and spacing from scratch.
* Icon Integration: Adding and styling Font Awesome icons for the email button and social media links.

## Getting Started

### Prerequisites

In order to run this project you need

* A Code Editor: A simple editor like VS Code to view or edit the HTML and CSS files.
* Live Server Extension: A VS Code extension used to preview the webpage live in the browser while coding.

### Setup

* Clone this repository to your desired folder
* Open the folder in your code editor (such as VS Code).
* Make sure your HTML file (index.html), CSS file (style.css), and profile image are all kept inside the same folder.
* Open index.html in your web browser (or launch it with the Live Server extension in VS Code) to view the card.

### Install

No Installation required for this Project

### Usage

To run the project, execute the following command

* Open the files in your web browser
* Click the Email button to launch your email app and send a message
* Click any of the footer icons to open my social media profiles in a new tab
* Edit index.html and style.css in VS Code to customize the photo, text, and links
